# Собственные видеоконсультации — 7 октября 2026

## Что изменилось

Вместо Jitsi используется встроенный WebRTC-интерфейс на body-state.ru. Обмен служебными сообщениями идёт через Next.js и Redis, аудио/видео — через собственный coturn на VPS сайта. Режим relay не передаёт сетевой адрес одного участника напрямую другому. Запись разговоров не реализована и не включена.

### Как пользоваться

1. Для оплаченной онлайн-записи комната появляется автоматически в «Онлайн-консультациях» админки и личном кабинете клиента.
2. Вход открывается за 15 минут до приёма и закрывается через 30 минут после его окончания. Отмена, перенос и статус оплаты проверяются сервером.
3. Для дополнительной встречи администратор указывает название и email существующего аккаунта клиента. Такая комната доступна 24 часа, не заменяет запись и не засчитывает посещение.
4. Специалист входит из админки, клиент — из своего кабинета. Ссылка не даёт доступ чужому аккаунту.
5. Перед звонком нужно проверить устройства, затем нажать «Войти в консультацию». Доступны отключение звука/камеры, режим «только звук», демонстрация экрана там, где её поддерживает браузер.
6. При потере связи можно выйти и войти повторно. После аварийного закрытия вкладки блокировка повторного входа снимается через 30 секунд.

## Защита и инфраструктура

- Разные роли специалиста и клиента назначаются сервером, не параметром URL.
- По одному устройству на каждую роль, атомарная аренда сессии Redis.
- Ограниченные по размеру и времени очереди сигналов без потери сообщений от конкурентных записей.
- TURN_SECRET хранится только на сервере. Браузерам выдаются временные HMAC-учётные данные на 3 часа.
- Удалены постоянные NEXT_PUBLIC_TURN_* credentials из сборки и конфигурации приложения.
- coturn: порты 3478 UDP/TCP, 5349 TLS, диапазон relay 49160–49259 UDP. Приватные и multicast-адреса запрещены как адреса получателей.
- Ограничения coturn: 256 МБ RAM, 50% одного CPU, квоты подключений и пропускной способности. Это ограничения, а не результат нагрузочного теста.
- Сертификат TURN обновляется через deploy-hook Certbot. Необязательная аналитика, декоративный фон и футер не загружаются в комнате.
- Миграция 020 добавляет привязку отдельных комнат к аккаунтам и индексы. Старые неподвязанные комнаты не предоставляют гостевой доступ. Данные старых комнат сохранены.

## Проверено

- TypeScript, ESLint, production Docker build.
- 36 интеграционных проверок на изолированной PostgreSQL/Redis: анонимный/чужой доступ, подмена роли, параллельные ICE-сообщения, повторный вход, устаревшие сессии, закрытие/истечение комнаты, неоплаченная и отменённая запись, перенос и ранний вход.
- Локально через реальные HTTP API: вход клиента, отображение комнаты в кабинете, определение клиентской роли.
- Через браузер: создание отдельной комнаты, переход специалиста, экран проверки устройств, отмена ожидания разрешения без включения устройств.
- TURN: повторный тест UDP/TCP/TLS — по 20 отправленных и полученных пакетов в каждом режиме. Первоначальный TLS-тест имел потери; итоговый упрощённый тест без RTCP прошёл. Это не длительный нагрузочный тест.
- Внешнее TLS-соединение к body-state.ru:5349 с проверкой сертификата.
- После первого запуска: health HTTP 200, защищённые API без авторизации HTTP 401, контейнер healthy, миграция применена.
- После финального обновления режима «только звук»: повторная production-сборка и публикация завершены с кодом 0, контейнер healthy, health 200 и защищённые API 401 проверены повторно.
- Старый hostname meet.body-state.ru больше не обслуживает Jitsi. Для него выпущен отдельный валидный TLS-сертификат с автоматическим обновлением; настроен переход в личный кабинет сайта.

При настройке coturn использована [официальная конфигурация проекта](https://github.com/coturn/coturn/blob/master/examples/etc/turnserver.conf).

## Ограничения приёмки

Не проверен полный разговор двух людей с реальными камерами/микрофонами, работа Safari/iOS и длительная сессия через мобильного оператора. Автоматические серверные проверки не заменяют этот тест. Перед первой клиентской консультацией необходимо провести контрольный разговор: специалист на компьютере, клиент на телефоне через мобильный интернет; проверить двусторонний звук, видео, выключение камеры, повторный вход и завершение.

В сетях, где запрещены и 3478, и 5349, соединение может не установиться: TLS на 443 занят Nginx сайта. SMS/email не подключались, клиенту можно передать ссылку вручную. Групповые звонки, запись и полноценный чат не входят в эту реализацию.

## Откат

На VPS сохранены исходники и конфигурация в `/opt/doctor-site/backups/video-20261007`, прежний образ приложения — `doctor-site-app:rollback-video-20261007`. Четыре контейнера Jitsi остановлены и удалены; конфигурация `/opt/docker-jitsi-meet` и образы сохранены для восстановления. База данных и загрузки не удалялись. Аддитивную миграцию можно оставить при откате приложения. Для полного отката требуется восстановить прежний TURN-конфиг и переменные окружения из защищённых резервных копий, а не только образ приложения.

На момент проверки после отключения Jitsi было доступно около 3 ГБ памяти и 2,7 ГБ диска. Свободное место нужно контролировать; вместимость одновременных видеозвонков нагрузочным тестированием не установлена.
