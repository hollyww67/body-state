# Body State Healthcare Design System V3

Ответственный: Петрович. Реализация расширяет существующую систему, а не создаёт новую библиотеку. Область — только `/admin` и портальные административные диалоги. Публичный сайт не получает новые токены.

## Foundations

Существующая violet-тема сохранена через те же `--bs-*` переменные. Семантические success/warning/info не заменяются цветом основного действия. Контраст проверяется независимым offline-тестом, а не определяется по названию токена.

Manrope — действующий шрифт проекта. Display 40/48, Page title 32/40, Section 24/32, Card 18/26–20/28, Body 16/24, Label 14/20, Caption 12/16. Плотная временная сетка сохраняет небольшие дополнительные подписи; полное название и действия доступны в карточке. Числа и время используют tabular numbers. Минимальные touch controls — 44px; на телефоне поля не мельче 16px.

Шкала отступов основана на 4px. Радиусы: control 8px, card 12px, overlay 16px, badge pill. Тени тонкие, без стеклянного фона или декоративного градиента. Outline-иконки — существующий Lucide; логотип — настоящий `/admin-icons/192.png`. Фотографии клиентов не подставляются; при наличии имени используются инициалы.

## Композиция

Desktop: sidebar 232px, topbar 76px, workspace 24px; Dashboard — основная область и rail 288px. Календарь сохраняет реальные режимы month/week/day, сервисный фильтр и нижние подробности выбранного дня. Начальный режим **month** сохранён, чтобы не менять исходный API range.

Mobile: брендовая шапка с журналом и пользовательским меню, существующая нижняя навигация. На календаре повторная брендовая шапка не показывается; остальные разделы доступны через «Ещё». Неделя/день отображают выбранный день без уменьшения семи desktop-колонок. Месяц остаётся доступным. На Dashboard остаются три приоритетных KPI; отзывы доступны через навигацию и desktop-сводку. Короткие действия занимают одну строку.

## Ограничения доменной модели

Не добавлены фиктивные специалисты/кабинеты, рост выручки, финансовый график без временного ряда, неподдерживаемые режимы и очередь «незапланированных» записей. MiniCalendar — справка по месяцу, не обещание доступности. Оплата и уведомления не включаются визуальными controls. Фактическая бизнес-логика сохранена.
