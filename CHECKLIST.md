
## 📱 Мобильные приложения (будущее)

### Приложение для клиента
- Запись на процедуры (БФМ, БРТ, Психология)
- Просмотр истории записей
- Напоминания о предстоящих сеансах (push)
- Магазин кремов (каталог, корзина, заказы)
- Видеозвонки для онлайн-психологии
- Чат с пространством
- Личный кабинет (заметки, рекомендации)
- Переключение темы (teal / violet)
- Промокоды и скидки
- Пуш-уведомления о подтверждении записи

### Приложение для админа
- Дашборд (заявки, заказы, выручка)
- Управление слотами (пакетное создание)
- Подтверждение/отмена заявок
- Управление заказами (статусы)
- Управление товарами (CRUD, фото)
- Вход в онлайн-консультацию (видеозвонки)
- FAQ бот (управление ответами)
- Переключение темы сайта
- Пуш-уведомления о новых заявках/заказах
- Просмотр аналитики (Umami)

### Технические заметки
- React Native или Flutter
- Единый API с сайтом
- JWT-авторизация
- Push-уведомления через Firebase Cloud Messaging
- Кеширование данных
- Оффлайн-режим для чтения
